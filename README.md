# Nocturne

Nocturne is a simple and calm **Todo List web app** designed with an evening-inspired theme. It lets users organize tasks into different projects, add task details, set priorities, edit or delete tasks, and manage projects.

## What I Learned

* JavaScript modules and importing/exporting
* DOM manipulation
* Events and event listeners
* Creating and editing Todo objects
* Working with projects and arrays
* Local Storage for saving data
* Dynamic HTML elements
* CSS styling and responsive design

## Features

* Add, edit, and delete tasks
* Task descriptions and due dates
* Low, medium, and high priorities
* Create and delete projects
* Switch between projects
* All Tasks view
* Tasks and projects stay saved after refreshing
